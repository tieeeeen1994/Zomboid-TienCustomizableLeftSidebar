# Tien's Customizable Left Sidebar

Make the left sidebar yours: drag its buttons into the order you like, hide the ones you never use, and set the space
between them.

- **Drag and drop.** The Customize button at the foot of the sidebar opens a window listing every sidebar button. Drag
  them up and down; the sidebar moves with you as you drag.
- **Hide what you never use.** Click a button's eye to hide or show it. The buttons below close the gap.
- **Spacing.** 0 to 40 pixels between buttons. Default 15, the game's own.
- **Works with other mods.** Buttons other mods add to the sidebar are listed too, and a new one shows up where its mod
  put it.
- **The game still decides.** Buttons the game only shows sometimes (Admin, PVP safety, War) keep following its rules,
  in the place you gave them. The window says when one is not shown right now.
- **Quick actions.** Right-click the sidebar to hide the button under the mouse, show hidden buttons again, or open the
  window.

## Opening the window

- The **Customize button** (rows and a pencil) at the bottom of the sidebar opens and closes it.
- **Customize the sidebar** (Options > Key Bindings > Customizable Sidebar) does the same from the keyboard. Not bound by
  default.
- **Right-click the sidebar** > Customize sidebar..., which always works, even with the Customize button hidden.

## Settings

All in the window:

- **Order** and **shown / hidden** for every button.
- **Space between buttons**: 0 to 40 px. Default 15.
- **Customize button**: full size (default), small, or hidden.
- **Show all** shows every hidden button; **Reset** puts the game's order, every button and the default spacing back.

The layout is saved on your computer in `Zomboid/Lua/TienCustomizableLeftSidebar.ini` and follows you to every save and
server. The hand slots at the top of the sidebar stay where they are.

Build 42 only. It changes only your own screen; in multiplayer the server needs it in its mod list like any other mod.
